# The Dome Sessions — Website prototype

Six-page responsive static website using supplied imagery and text.

## Preview
Run `python3 -m http.server 8000` in this folder, then open `http://localhost:8000`. Alternatively open `index.html` directly in a browser (embedded video/audio will need an internet connection).

## Publishing
Upload all files and the `assets` directory to your hosting provider, or deploy as a static site on Netlify / Cloudflare Pages. Domain and SSL setup are separate.

## Pages
- `index.html` — The Film, trailer, stills, credits, press, festival graphics
- `vinyl.html` — album, photos, Bandcamp embed
- `team.html` — Firas and Anthony biographies
- `heritage.html` — UNESCO heritage site overview
- `dome.html` — architecture and acoustics
- `contact.html` — production contact

## Editorial and technical items to confirm
- Runtime, format, language, year, country, and screening format were not supplied; no specifications were fabricated.
- Historical photographs and their reproduction rights are still needed for the heritage and Dome pages.
- Biographies and project description are shortened/adapted from supplied documents. Review before publication.
- Film's formal title treatment, still-image credits, and any legal/privacy wording should be approved.
- The Vimeo embed will only play if the video's embed/privacy settings permit playback on the site.
- Festival graphics from the archive are displayed as official-selection marks, not awards.
- Confirm the final Bandcamp release/player configuration and website analytics preferences.
- The website uses Google Fonts; host fonts locally if you want no external font requests.
